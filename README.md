# Phone-Ordering-System
A phone ordering system developed using C# and Microsoft Visual Studio for calculating phone orders in Kenyan shillings (KSh).

## Features

- Enter quantities for blue and pink phones
- Calculate the subtotal, 16% sales tax, and total
- Clear the order or exit the app

## Prices

- Blue phone: KSh 20,000
- Pink phone: KSh 22,000

## Run the project

1. Open `Phone Ordering System.slnx` in Visual Studio.
2. Start the app with **F5** or the **Start** button.

## Built with

- C#
- Windows Forms
- Microsoft Visual Studio
